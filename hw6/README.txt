MercyMed — HTML/CSS prototype for AUCA COM-360 Assignment 6

Place the WHOLE contents of this folder into auca_html/hw6/.
Open index.html in a browser, or view at https://eldarmamin.github.io/auca_html/hw6/ after uploading and enabling GitHub Pages.

Pages: index.html, services.html, team.html, about.html, mobile-clinics.html, contact.html, appointment.html.
All page links are relative, so they work under /auca_html/hw6/.

No npm, React, TypeScript, build tools, database, or web server required.
style.css contains responsive styles; script.js handles language switches (EN/RU/KG), team filters, mobile navigation, and simulated booking.
The appointment page is a DEMO: nothing is sent or stored.

Source: converted from user-provided Lovable GitHub ZIP (mercy-med-language-bridge-main.zip). Brand colours and original copy preserved. Image files were not included in that ZIP (only Lovable-specific .asset.json pointers): real MercyMed team, clinic and diagnostic photos and logo have therefore been extracted from the supplied client presentation PDF. Some photographs are less detailed than the Lovable assets.

All content is provisional pending MercyMed approval. Avoid publishing real patient data.
